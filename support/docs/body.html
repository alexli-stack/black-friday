    GOOD QUESTIONS. CLEAR ANSWERS.

    A few things to know.

    Where should I start with a new machine?

    Choose your series above, then read the matching user manual and safety instructions before installation. Check the model, generation, and laser source on your machine. Find the latest manuals in our manual library.

    Which material settings should I use?

    Select the settings that match your laser source and wattage. Materials, thicknesses, and machine configurations vary, so always run a small material test. Never process an unknown material; check your machine manual for material and safety guidance.

    Can I use Hydra Gen1 resources for Hydra Gen2?

    Use documentation for your exact generation and laser configuration. Shared series names do not guarantee identical procedures or parameters. Start with the Hydra Gen2 manual, or confirm the correct resource with technical support.

    Should I update my firmware?

    Only use firmware and instructions confirmed for your exact model and controller. Contact OneLaser technical support before updating if you are unsure which version applies to your machine.

    What should I include in a support request?

    Include your machine model, serial number, order number, software version, and a clear description of the issue. Photos, a short video, and the exact error message help the team understand the problem. Submit these through the official support portal.
