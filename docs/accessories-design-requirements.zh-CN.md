## 2. 当前页面的具体问题

1. **兼容信息不一致**：公开页面中 Gen1 镜筒的说明限制 Gen1，但标签同时出现 Gen2；Galvo Grip 的说明针对 fiber/UV，却出现在 CO₂ 系列标签中。不能把筛选命中写成“已确认适配”。本实现将 Gen1 镜筒限制在 Gen1 候选范围，将 Galvo Grip 保留在全目录并要求咨询。
2. **机器系列不是最终规格**：Hydra 代际、玻璃管/RF、旋转电机/接头、滤芯所属净化器与滤芯阶段，都可能决定最终选型。
3. **升级件和维护件的动机不同**：旋转轴、增高底座对应新应用；镜片、滤芯、管件对应维护。只显示商品列表增加理解成本。
4. **FAQ 应遵循技术条件**：不能笼统声称 Hydra 全系都需要同一种水冷，也不能把机器系列标签当滤芯规格。
5. **价格、商品数量会变化**：抓取时 HTML 快照包含 26 张商品卡，搜索索引此前显示 27；不把历史索引数量或价格作为实时事实。

## 3. 目标用户与关键路径

- 老用户知道机器：选机型 → 类别/搜索 → 阅读前置条件 → 对比候选 → 进入产品页确认变体后购买。
- 升级用户知道用途：选自己的机器 → 在分类导航中选择旋转/冷却/过滤等类别 → 阅读对应产品。
- 维护用户知道部件：搜索名称 → 价格/类别缩小结果 → 确认代际、尺寸或设备型号。
- 不确定型号的用户：无需填写额外表单，即可打开官网联系页面或知识库。

## 5. 品牌视觉规范

2026-11-17 重新检查 [OneLaser 首页](https://www.1laser.com/)、[xTool 配件页](https://www.xtool.com/collections/accessory) 和 [WeCreat 配件页](https://wecreat.com/collections/accessories) 的实际浏览器截图。OneLaser 首页采用橙红操作色、黑白强对比、Certia 字体、圆角按钮与设备实物图。xTool 配件目录的灰底白卡与大图层级、WeCreat 的清晰图片/名称/价格顺序可借鉴。以下调整是视觉设计选择，未经转化率实验验证。

- 主色沿用 `#E7310E`；深色区域采用 `#11151C`，目录背景采用 `#F3F4F7`，浅橙 `#FFF0EA` 用于选中标签与分类图标。白色产品卡与浅灰背景建立层级，避免整页只有细线和白底。
- 使用官网原版 SVG Logo、Certia / Certia-ExtraBold 和六个真实机型缩略图。图片只来自 OneLaser；机型图片来源记录于 `docs/accessories-machine-image-sources.json`。系列图以具体机型作代表，不表示系列所有型号外观相同。
- 首个模块仍为选机区：深色背景、有限橙红光晕、橙红分隔线、图文同排的六个机型卡片；卡片高度为桌面 88px、手机 86px，不换行，超宽左右滚动。机型卡片使用白底、深色文字和浅灰图片衬底；选中态使用浅暖色底、橙红边框及勾选标记，保留图片对比度。
- 分类导航增加 SVG 用途图标与数量圆角标签；筛选栏采用独立白色容器；专家帮助卡采用与选机栏呼应的深色背景。
- 商品卡采用 16px 圆角、大幅真实产品图、用途标签、突出价格和双操作按钮。桌面端橙红 Add to cart 与描边 Learn More 并排，窄屏上下排列，避免挤压文字。悬停有轻微阴影和位移，reduced-motion 下关闭位移。
- FAQ 采用浅灰圆角容器；页尾专家模块沿用深色与橙红 CTA，形成完整品牌层级。仍不在选机前添加营销大图、促销倒计时，也不恢复用户已移除的辅助文案。

视觉覆盖样式独立保存为 `assets/accessories-brand.css`，便于调整品牌样式而不改动购物交互。已新增 page.accessories 模板，沿用当前主题 header/footer；GitHub 预览同步官网当前公共导航快照。接入与刷新方式见 accessories-theme-integration.zh-CN.md。

## 6. 数据、性能和无障碍要求

当前仓库实现是独立静态页面，目录源于 2026-11-16 官网 HTML；2026-11-17 从每个官网商品 .js 端点补充真实变体 ID、价格及可售快照。数据位于 `assets/accessories-data.js`。图片与 Certia 字体从 OneLaser 官网下载并保存到仓库；数据保留原图片 URL 便于追溯，商品详情跳转官网。价格含多变体情况，卡片使用“From”；实际价格/库存/变体需在产品页确认。静态页使用标准表单跳转官网购物车，不在第三方预览域调用 Shopify Ajax Cart，也不伪造本地加购成功。可售状态是采集快照，提交时由 Shopify 进行最终校验；采集后售罄可能在官网返回错误，页面不保证实时库存。

搜索、类别、机型、最高价与排序记录到 URL；比较选择仅本次页面会话保留。所有抓取字符串做 HTML 转义；脚本不采集个人信息。CSS/JS 无前端框架依赖；非首屏商品图片懒加载，图片有明确尺寸；使用 font-display: swap。支持 reduced-motion、跳过链接、可见键盘焦点、原生对话框、结果 live region、语义化表头和表单标签。目标为 WCAG 2.1 AA，正式发布前仍需自动扫描和人工辅助技术复核。

## 7. Shopify 正式接入需求

仓库包含黑五活动的部分 Shopify 文件，但没有完整主题配置、layout 或正式主题连接。因此本次新增独立 HTML/CSS/JS 页面，不直接替换线上集合模板。

正式接入时：

1. 在未发布主题中新增 `collection.accessories` 模板，复用线上 header/footer、现有 product-card、货币和本地化能力。
2. 使用 Shopify Search & Discovery 原生机型、类别、价格、库存筛选和 `collection.filters`；通过 Section Rendering API 更新结果，保留无 JS 的 GET 表单路径。数据量扩大时采用服务端分页，禁止仅对第一页做客户端过滤。
3. 商品名、价格、可售变体、图片使用 Liquid 产品对象；图片使用 image_url/image_tag、响应式宽度；价格遵循 money/localization。取代本次静态目录。
4. 先经产品团队审核并纠正当前兼容数据。机器 family 只作候选；独立记录具体代际/激光源/接头/滤芯设备型号/前置配件。字段命名沿用已存在的 custom.accessories_features_list 与 custom.accessories_collection_category，扩展字段另行审核，不凭名称猜兼容关系。
5. 当前独立页已支持真实变体的标准表单加购与多变体选择；正式主题内改用实时可售状态和本地化 form action。多变体必须选配置；需人工核对时引导咨询。若增加不跳转的加购体验，再按 Shopify Ajax Cart 实现错误、售罄、重复提交及现有抽屉刷新逻辑。
6. 不向线上写入样例产品、不改变产品价格、不替换现有集合 URL；审核通过后分配模板并测试实际购买路径。

## 8. 衡量效果与发布验收

建议事件：machine_select、goal_select、filter_change、zero_results、compare_open、product_click、expert_click。参数限类别/机型/产品 ID，不采集搜索框中的潜在个人资料。当前静态版未嵌入分析追踪。

上线后按移动端/桌面、机型区分观察：配件详情点击率、选机后零结果率、咨询率、配件加购率、兼容原因退换货率。对比现有页面做 A/B 或同周期分析，不预设提升百分比。

必须验收：375/390/768/1440 宽度无横向溢出；机型与类别组合、0 元上限、负数处理、无结果、重置、URL 恢复；比较上限与模态关闭；站外产品链接；当前价格与兼容数据复核；图片加载失败和慢网体验；正式主题下真实加购/变体/售罄/购物车测试。

## 9. 本次验证结果

2026-11-17 使用 Chromium/Playwright 验证：默认首模块为紧凑单行选机，下方立即显示全目录和筛选栏；选择 XRF 后只出现对应候选产品；分类标题与结果匹配；Learn More 详情链接存在；URL 刷新恢复；空结果重置保留机型；单变体表单提交真实 ID、quantity=1、return_to=/cart；多变体默认空值、必选校验、选择 ID 与数量传递；弹窗 Esc 关闭；All machines 与刷新恢复；重新选择 Hydra Gen1 后更新商品；375/390/768/1440 宽度无横向溢出；手机筛选面板与规格弹窗布局。

表单提交在测试浏览器拦截并检查内容，没有向真实购物车写入，也没有下单。未对官网跨站表单的实际响应、实时售罄错误或支付做端到端验证，不声称完成真实交易验证。preview/ 中保存新版桌面首屏、商品目录与手机截图。
